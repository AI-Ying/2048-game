# 2048 Game

经典 2048 小游戏，单页应用（HTML/CSS/JS），无需联网即可运行。v1.0.1 以动物 emoji 直接展示数字。

## 功能

- 4x4 棋盘，经典 2048 规则
- 数字动物化展示（2→小鼠 … 2048→神龙）
- 键盘方向键 / WASD / 滑动 控制移动
- 实时得分 + 最高分（localStorage 持久化）
- 触屏滑动支持，移动端适配
- 胜利（2048）/ 失败判定

## 运行

直接用浏览器打开 `index.html` 即可，或用任意静态服务器：

```bash
python3 -m http.server 8080
```
